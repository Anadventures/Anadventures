# Next Steps - GitHub Desktop Setup

## ✅ You've Downloaded GitHub Desktop!

Now follow these steps:

---

## Step 1: Install GitHub Desktop

1. Go to your **Downloads** folder
2. Find `GitHubDesktop.zip` (or similar)
3. **Double-click** to extract it
4. You'll see `GitHub Desktop.app`
5. **Drag** `GitHub Desktop.app` to your **Applications** folder
6. Open **Applications** and **double-click** `GitHub Desktop.app`

**If you see a security warning:**
- Go to **System Settings** → **Privacy & Security**
- Click **"Open Anyway"** next to GitHub Desktop

---

## Step 2: Sign In to GitHub

1. GitHub Desktop will open
2. Click **"Sign in to GitHub.com"**
3. Enter:
   - **Username or email**: `anadventures` (or your GitHub email)
   - **Password**: Your GitHub password
4. Click **"Sign in"**
5. Authorize GitHub Desktop if prompted

---

## Step 3: Add Your Anadventures Project

1. In GitHub Desktop, click **"File"** → **"Add Local Repository"**
2. Click the **"Choose"** button
3. Navigate to: `/Users/ayushmalik/Desktop/Anadventures`
4. Select the **Anadventures** folder
5. Click **"Add Repository"**

You should now see all your files listed in GitHub Desktop!

---

## Step 4: Publish to GitHub

1. At the top of GitHub Desktop, you'll see a button: **"Publish repository"**
2. Click **"Publish repository"**
3. In the popup window:
   - **Name**: `Anadventures` (should be pre-filled)
   - **Description**: "Portfolio website by Ananya Solanki"
   - **Keep this code private**: Uncheck this if you want it public
4. Click **"Publish Repository"**

GitHub Desktop will upload all your files to GitHub!

---

## Step 5: Verify It Worked

1. Wait for the upload to complete (you'll see "Published" ✅)
2. Go to: **https://github.com/anadventures/Anadventures**
3. You should see all your files there!

---

## What Gets Uploaded?

✅ **Will be uploaded:**
- All Python files (app.py, wsgi.py, etc.)
- All templates
- All static files (images, etc.)
- Documentation files
- Configuration files

❌ **Won't be uploaded** (protected by .gitignore):
- config.py (contains API keys - secure!)
- instance/ folder (database)
- __pycache__/ (cache files)

## Need Help?

If you get stuck:
- **"Can't find repository"**: Make sure you're selecting the right folder
- **"Authentication failed"**: Check your GitHub username/password
- **"Repository already exists"**: The repo might already be on GitHub

Let me know if you need help with any step! 🚀
